Privacy Agent Demo - iFrame Method

This demonstrates the concept of an AI agent that helps remove personal information from websites.

Note: This demo has significant limitations due to browser security restrictions.

Security Limitation

Due to browser security restrictions (Same-Origin Policy), direct interaction with other sites via iframe is extremely limited.

The frame will load, but JavaScript cannot access its contents if from a different origin.

Click "Load Site" to see the limitation in action.

Limitations of iFrame Method

  • Cross-Origin Restrictions: Cannot access DOM of other websites
  • Content Security Policy: Many sites block iframe embedding entirely
  • No ability to handle authentication
  • Cannot navigate between pages reliably
